# Zentemi Android

Proyecto Android en Kotlin + Jetpack Compose. Consulta `../LEEME_Actualizacion_Zentemi.md` para revisar los cambios de navegación y aprendizaje, el inventario de vocabulario y audio, los criterios de asociación y las pruebas UAT pendientes.

La biblioteca de grabaciones está dentro de `Juegos > Biblioteca de audios`. El diccionario se abre desde `Cultura`. Abre esta carpeta en Android Studio, sincroniza Gradle y ejecuta `app` en un emulador o dispositivo. El wrapper apunta a Gradle 8.9.
